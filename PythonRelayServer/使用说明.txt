========================================
   IPv6 中继服务器 (Python + PyQt6)
========================================

这是完全用 Python 重写的版本，可以轻松打包成独立 EXE！

快速开始：

方法一：直接运行 Python 脚本（开发用）
1. 确保已安装 Python 3.8+
2. 安装依赖：pip install -r requirements.txt
3. 运行：python main.py 或双击 run.bat

方法二：打包成独立 EXE（推荐，发布用）
1. 确保已安装依赖：pip install -r requirements.txt
2. 双击运行 build.bat
3. 等待打包完成，在 dist 文件夹中找到 IPv6中继服务器.exe
4. 现在你可以把这个 EXE 文件发给任何人，双击直接运行！

----------------------------------------

重要说明：

- 本服务端与原来的 Minecraft Mod 完全兼容！
- Minecraft Mod（客户端）还是原来的 JAR：IPv6Relay-1.0.0.jar
- 这个 Python 版的是替代原来的 Java 服务端的！
- 两者功能完全一样，协议 100% 兼容！
