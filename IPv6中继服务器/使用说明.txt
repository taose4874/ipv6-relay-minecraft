========================================
     IPv6 中继服务器 - GUI 版
========================================

使用方法：
1. 确保已安装 Java 8 或更高版本
2. 双击运行 「启动服务.bat」 或直接双击 「IPv6RelayServer-GUI.jar」
3. 在弹出的窗口中点击 「🚀 启动服务」
4. 现在可以开始使用了！

功能说明：
- 控制端口：25566（默认）
- 支持 IPv4/IPv6 双栈
- 美观的 GUI 界面
- 实时日志查看

注意事项：
- 需要开放防火墙相关端口
- 如有问题请检查 Java 是否正常安装
